# CORRE+

## Objetivo
CORRE+ é um sistema de recomendação de tênis para corrida,
caminhada, trilha e terrenos híbridos.

## Stack atual
- HTML5
- CSS3
- JavaScript
- JSON
- Git/GitHub

## Restrições
- Não utilizar frameworks no MVP.
- Mobile First.
- Manter identidade visual definida em DESIGN.md.
- Não criar novas cores sem necessidade.
- Não utilizar border-radius nos componentes principais.
- Manter separação entre CSS global, componentes e páginas.
- JavaScript deve ficar separado do HTML.
- Dados dos tênis devem ficar separados da lógica.
- Não alterar arquivos não relacionados à tarefa.

## Regra para IA
Antes de modificar arquivos:
1. analisar a estrutura existente;
2. identificar dependências;
3. propor alterações;
4. implementar somente o necessário;
5. informar quais arquivos foram modificados.
