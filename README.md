# CORRE+ — Performance Inteligente

> Plataforma em desenvolvimento voltada para corredores, com foco em desempenho, comparação de tênis e organização de informações relevantes para treino e corrida.

**CORRE+** é um projeto pessoal criado para estudo e prática de desenvolvimento web, pensado inicialmente para o mercado brasileiro. O projeto está atualmente em **fase de testes e desenvolvimento ativo**, portanto funcionalidades, estruturas visuais e decisões técnicas podem sofrer alterações.

---

## Sobre o projeto

O CORRE+ nasceu da combinação entre uma necessidade real observada no universo da corrida e meu interesse em transformar essa ideia em uma aplicação web funcional.

A proposta é criar uma plataforma que reúna informações úteis para corredores em um único ambiente, permitindo futuramente consultar, comparar e analisar tênis de corrida e outros dados relacionados à performance.

O projeto também funciona como um **laboratório prático de desenvolvimento**, no qual aplico conhecimentos de:

* HTML
* CSS
* JavaScript
* responsividade
* UI/UX
* organização de código
* arquitetura de interface
* consumo e organização de dados
* Git e GitHub
* desenvolvimento assistido por inteligência artificial

O objetivo não é apenas construir uma interface visualmente agradável, mas desenvolver uma aplicação com estrutura capaz de evoluir para algo mais completo.

## Conceito

O nome **CORRE+** representa a ideia de ir além da corrida básica.

A proposta é combinar **corrida + dados + tecnologia + análise** para transformar informações espalhadas em uma experiência mais organizada para o corredor.

O projeto também busca explorar uma abordagem mais técnica na apresentação das informações, utilizando uma identidade visual inspirada em interfaces modernas de tecnologia e performance.

## Desenvolvimento com IA

Um dos aspectos importantes deste projeto é justamente a utilização consciente de inteligência artificial durante o desenvolvimento.

As IAs não são responsáveis isoladamente pelo projeto.

**O desenvolvimento, as decisões, a implementação, os testes, a validação e a direção do produto são realizados por mim.**

As ferramentas de IA funcionam como **assistentes de desenvolvimento**, auxiliando em partes do processo, mas não substituindo o desenvolvedor.

Na prática, o fluxo envolve:

```text
IDEIA
  ↓
PLANEJAMENTO
  ↓
DESIGN / PROTÓTIPO
  ↓
IMPLEMENTAÇÃO
  ↓
ASSISTÊNCIA POR IA
  ↓
REVISÃO DO CÓDIGO
  ↓
TESTES
  ↓
AJUSTES
  ↓
VALIDAÇÃO
```

As sugestões geradas por IA são analisadas antes de serem incorporadas ao projeto. Código gerado automaticamente pode ser modificado, descartado ou reescrito conforme a necessidade.

Isso faz parte do objetivo do projeto: **aprender a utilizar IA como ferramenta de desenvolvimento sem deixar de compreender e controlar o código produzido.**

## Arquitetura CSS

O CSS está sendo organizado de forma modular, buscando evitar um único arquivo excessivamente grande.

A estrutura atual utiliza uma camada de arquivos responsáveis por diferentes funções.

Exemplo:

```text
reset.css
    ↓
tokens.css
    ↓
main.css
    ↓
componentes específicos
    ↓
home.css
navbar.css
outros estilos
```

### `reset.css`

Responsável pela normalização básica dos estilos do navegador.

### `tokens.css`

Responsável por centralizar valores reutilizáveis da interface, como:

* cores;
* tipografia;
* espaçamentos;
* bordas;
* medidas;
* propriedades visuais.

### `main.css`

Funciona como camada principal de importação e organização dos estilos.

### CSS específico por componente/página

Arquivos como:

```text
home.css
navbar.css
```

concentram regras específicas de determinadas áreas da interface.

Essa arquitetura pode continuar evoluindo conforme a aplicação ganhar novos componentes.
